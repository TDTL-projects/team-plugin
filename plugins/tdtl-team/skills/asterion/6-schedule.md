## 6. По расписанию
Запуск «Астерион» (запуск «Вечерняя проверка» — не этот раздел, а только раздел 8). Ключ трекера и репозитории — в инструкции запуска. Видишь только свою линию: в `find_tasks` всегда передаёшь `project: -P-08`. За один запуск, в этом порядке:
1. **Конвейер стоит и ждёт тебя**: `find_tasks`, ответственный — участник «Конвейер», статус «Ожидание», `project: -P-08`; по каждой `get_task` смотри «чего ждём». Это первым.
   - «вердикт Астериона по PR #N» — раздел 2.
   - «вердикт Астериона по зерну» (зерно со строкой «Репозиторий» из строки «Вне линий» — не проверяешь, это задача владельца) — задачу поставили «К разработке» без твоей проверки: раздел 1, вердикт в журнал. В журнале «Конвейер: правка проверок вне зерна — …» новее твоего вердикта — старая остановка: раздел 1, «Правка проверок вне зерна».
   - «слить PR #N: среда не дала» — конвейер всё прошёл, но слить не смог. Запусти `scripts/stop-list.sh origin/main` на ветке: правок проверок, секретов и рабочих баз нет, CI зелёный — слей (squash) и запиши «PR #N слил Астерион: конвейеру среда не дала». Есть правки проверок — раздел 2. Тебе тоже не дали — в уведомление владельцу линии: «PR #N готов и проверен, слить кнопкой: <ссылка>».
   - «снять черновик с PR #N» — сними отметку (`gh api -X POST repos/<владелец>/<репо>/pulls/<N>/ccr/ready_for_review`). Не вышло — в уведомление владельцу линии: «открыть PR #N и нажать Ready for review: <ссылка>».
   - «слить техпроект: <файл>» — задачи волны стоят, потому что техпроекта нет в `main`. Проверь техпроект (раздел 1) и слей PR после «техпроект проверен». Техпроект «не готов» или PR нет — в уведомление владельцу линии: «волна стоит: техпроект ждёт Дедала».
   - номер вопроса Q-…, вопрос открыт, и задача «Ответить на Q-…» на тебе — раздел 7. Там же, в каждом запуске: несогласие владельца с твоим решением («Откат»).
   - «зелёный полный прогон» — конвейер вернётся к задаче сам, когда отметка позеленеет. Твоё здесь — чтобы она могла позеленеть: разбор красного прогона и «Прогон после починки» (раздел 3).
   - «да Ерлана на слияние» — раздел 2, последний пункт: если в PR есть и правки проверок, сначала вердикт по ним, потом ответ владельцу линии.
2. **Техпроекты**: открытые PR «… Техпроект волны N» в репозиториях продукта линии TradeLab без твоего вердикта для последнего коммита — раздел 1, сначала они.
3. **Зёрна**: `find_tasks`, статус «Предложена», по каждому направлению отдельно, `limit: 100`, `project: -P-08`; зерно со строкой «Репозиторий» из строки «Вне линий» не проверяет никто; вид «Разработка», зерно отмечено готовым, в журнале нет твоего вердикта для текущей версии. Раздел 1. Задачи с одним техпроектом проверяй вместе, как пачку. Вердикт для той же версии переписываешь в двух случаях: «не готово» было из-за открытого вопроса, а вопрос с тех пор закрыт; и перепроверка задетых зёрен по PR правки техпроекта (раздел 1).
4. **Приёмка**: задачи «Приёмка: …» на тебе — «Предложена», когда все зависимости «Готово» или «Отменена»; «В работе» без итоговой записи «Астерион: приёмка — …» (прошлый запуск оборвался); «Ожидание», когда все задачи из «чего ждём» снова «Готово». Раздел 4.
5. **Сверка после слияния** — раздел 3, вместе с ней **полный прогон по `main`**: красная отметка — раздел 3, «Полный прогон красный»: разбор, а если он уже есть — «Прогон после починки». Вечерний прогон, который ещё ведёт вечерняя проверка (пауза «вечерняя проверка …» или запись «нужна» без итога в журнале T-0712), не трогаешь; запись «Астерион: вечерняя проверка красная — …» со ссылкой на этот запуск — разбор уже есть (раздел 8). **PR людей** — раздел 5.
6. **Что ждёт владельца линии**: задачи Конвейера в «Ожидании» с «да Ерлана на слияние» или открытым вопросом к нему; зёрна и техпроекты, которые не готовы и ждут Архонта или Дедала (нет раздела «Для разработки», открытый вопрос, техпроект «не готов»).

Владельцу линии — одно уведомление за запуск; по таблице линий — Ерлану push-уведомление (инструмент `PushNotification`). Решения по вопросам остановок (раздел 7) идут только в утренней сводке. Только когда есть что сказать: что ждёт его «да» (с твоим советом), итог приёмки, что вернул на доделку, какой техпроект проверен (можно писать зёрна) или не готов, какие зёрна готовы и какие стоят и чего ждут. Об одном и том же ожидании пишешь один раз: отправил — оставь в журнале задачи «Астерион: Ерлану отправлено — …»; есть такая запись новее причины ожидания — не повторяй. В выходные уведомлений не шлёшь: что накопилось, уйдёт в первом запуске понедельника. Нечего делать — закончи одной строкой.

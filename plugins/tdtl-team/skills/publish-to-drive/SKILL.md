# Выложить на Диск

Нужен коннектор Google Drive (рабочий аккаунт). Нет его — скажи, как подключить: «Персонализация» → «Коннекторы» → Google Drive.

1. **Что выкладываем.** Файл из рабочей папки — уточни, если неясно. Спроси «сдаёшь на проверку?»: на Диск идёт только сдаваемая версия, промежуточные правки остаются в рабочей папке.
2. **Данные клиентов.** Файл с данными клиентов — в названии или внутри: номера ДТ, договоров, счетов, БИН, названия клиентов, их суммы — кладём только в папку, начинающуюся с «_», внутри нужного направления («_old» не для этого — это архив версий, шаг 7). Не знаешь, что внутри, — спроси человека. Если данные клиента только в названии, можно вместо этого переименовать (с согласия человека).
3. **Куда.** Направление задачи (из трекера, `get_task`) определяет папку на общем диске «Цифровизация TD-TL» (Google Диск → «Общие диски»):
   | Направление | Папка | ID |
   |---|---|---|
   | TradeLab (TL) | TL | `1B9SLMaMG9DLfxznN95O3GRUBxU_QwPKz` |
   | Терминал (TD) | TD | `1EIU2gMwBC_uOf76FaA6ETjnDORloEH9N` |
   | Брокер (XP) | XP | `1jKz6UFq4WKA78Wq26NhUHa5--V9lQxFP` |
   | Система управления (ORG) | корень общего диска | `0ACzm0H8ZXHEaUk9PVA` |
   Внутри папки направления — подпапка на подпроект (D-0022): задача входит в SP-03 → подпапка «SP-03 Кабинет клиента брокера» (номер и название подпроекта из трекера). Найди её: `search_files` с `parentId = '<id папки направления>' and title contains 'SP-03'`. Нет — создай (`create_file`, тип папка, название «SP-xx <название подпроекта>»). Задача входит прямо в проект или документ про весь проект — в саму папку направления. Папку на задачу не заводим; исключение — файлов по задаче больше пяти: тогда папка «T-xxxx <что в ней>» внутри подпапки подпроекта, как «T-0296 Скриншоты экранов» (D-0109). Папки «Референс» — для старого справочного материала, новые файлы туда не клади. Существующие файлы на Диске не перезаписывай и не удаляй — новая версия = новый файл с датой или номером версии в названии, прежняя уходит в «_old» (шаг 7).
4. **Название.** Начинается с номера задачи, дальше — понятно, что это и для чего: «T-0040 Образцы выгрузок АСУ», «T-0005 Перечень документов брокера для оформления ДТ, v2». Документ про весь проект — с номером проекта: «P-06 Рамка терминала». Документ большого разбора (D-0040) — «T-0124 Разбор 06.11 — схема процессов брокера»: в нём анализ, правки и пояснения, а решения и вопросы — номерами и ссылками, их текст живёт в трекере. Других кодов и сокращений не добавляй. По номеру в названии опись Диска связывает файл с задачей (решение D-0014 в трекере).
5. **Выложить** через Google Drive (создать файл в нужной папке). Документы Word и Markdown — как Google Документ, таблицы — как Google Таблица, если человек не просит иначе.
6. **Привязать к задаче.** Инструмент трекера `link_document`: задача (или проект, если документ про весь проект), ссылка на выложенный файл, его название. Файл сразу виден в карточке в «Документах и схемах» — ждать обхода описи не нужно. Задачи нет — спроси номер.
   Не вышло (в коннекторе нет `link_document` или ошибка) — не останавливайся: файл уже на Диске, а опись привяжет его сама при обходе по номеру в начале названия. Скажи об этом человеку одной строкой.
7. **Прежняя версия** (D-0109) — если это новая версия файла, который уже лежит на Диске и привязан к задаче:
   - номер прежней (#N) и ссылка — в карточке задачи (`get_task`, «Документы и схемы»); какая из них прежняя, не очевидно — спроси;
   - отвяжи прежнюю от задачи: `unlink_document` с #N (новая привязана в шаге 6);
   - переложи прежнюю в «_old» рядом — подпапку ровно «_old» в той же папке, где лежит файл (`search_files` с `parentId = '<id папки>' and title = '_old'`); нет — создай (`create_file`, тип папка). Перекладывать — `update_file` с новым `parentId`: ссылка на файл не меняется. Сначала посмотри у файла `canMoveItemWithinDrive` (не видно — `get_file_metadata`): false — не перекладывай, скажи человеку со ссылкой, что переложить надо в Диске руками. Drive отказал — не повторяй и не копируй, скажи так же.
8. **Ссылка в журнал.** `add_worklog` по задаче: «Выложил на Диск: <название>» и ссылка на новый файл; была прежняя — «прежняя версия — в _old».
9. Ответь человеку ссылкой одной строкой.

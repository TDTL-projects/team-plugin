# Выложить на Диск

Нужен коннектор Google Drive (рабочий аккаунт). Нет его — скажи, как подключить: «Персонализация» → «Коннекторы» → Google Drive.

1. **Что выкладываем.** Файл из рабочей папки — уточни, если неясно. Черновики не выкладываем: спроси «это готовая версия?».
2. **Данные клиентов.** Файл с данными клиентов — в названии или внутри: номера ДТ, договоров, счетов, БИН, названия клиентов, их суммы — кладём только в папку, начинающуюся с «_», внутри нужного направления. Не знаешь, что внутри, — спроси человека. Если данные клиента только в названии, можно вместо этого переименовать (с согласия человека).
3. **Куда.** Направление задачи (из трекера, `get_task`) определяет папку на общем диске «Цифровизация TD-TL» (Google Диск → «Общие диски»):
   | Направление | Папка | ID |
   |---|---|---|
   | TradeLab (TL) | TL | `1B9SLMaMG9DLfxznN95O3GRUBxU_QwPKz` |
   | Терминал (TD) | TD | `1EIU2gMwBC_uOf76FaA6ETjnDORloEH9N` |
   | Брокер (XP) | XP | `1jKz6UFq4WKA78Wq26NhUHa5--V9lQxFP` |
   | Система управления (ORG) | корень общего диска | `0ACzm0H8ZXHEaUk9PVA` |
   Внутри папки направления — подпапка на подпроект (D-0022): задача входит в SP-03 → подпапка «SP-03 Кабинет клиента брокера» (номер и название подпроекта из трекера). Найди её: `search_files` с `parentId = '<id папки направления>' and title contains 'SP-03'`. Нет — создай (`create_file`, тип папка, название «SP-xx <название подпроекта>»). Задача входит прямо в проект или документ про весь проект — в саму папку направления. Папку на задачу не заводим. Папки «Референс» — для старого справочного материала, новые файлы туда не клади. Существующие файлы на Диске не перезаписывай и не удаляй — новая версия = новый файл с датой или номером версии в названии.
4. **Название.** Начинается с номера задачи, дальше — понятно, что это и для чего: «T-0040 Образцы выгрузок АСУ», «T-0005 Перечень документов брокера для оформления ДТ, v2». Документ про весь проект — с номером проекта: «P-06 Рамка терминала». Других кодов и сокращений не добавляй. По номеру в названии опись Диска связывает файл с задачей (решение D-0014 в трекере).
5. **Выложить** через Google Drive (создать файл в нужной папке). Документы Word и Markdown — как Google Документ, таблицы — как Google Таблица, если человек не просит иначе.
6. **Привязать к задаче.** Инструмент трекера `link_document`: задача (или проект, если документ про весь проект), ссылка на выложенный файл, его название. Файл сразу виден в карточке в «Документах и схемах» — ждать обхода описи не нужно. Задачи нет — спроси номер.
   Не вышло (в коннекторе нет `link_document` или ошибка) — не останавливайся: файл уже на Диске, а опись привяжет его сама при обходе по номеру в начале названия. Скажи об этом человеку одной строкой.
7. **Ссылка в журнал.** `add_worklog` по задаче: «Выложил на Диск: <название>» и ссылка.
8. Ответь человеку ссылкой одной строкой.

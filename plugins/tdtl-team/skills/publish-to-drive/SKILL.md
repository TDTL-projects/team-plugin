# Выложить на Диск

Нужен коннектор Google Drive (рабочий аккаунт). Нет его — скажи, как подключить: «Персонализация» → «Коннекторы» → Google Drive.

1. **Что выкладываем.** Файл из рабочей папки — уточни, если неясно. Черновики не выкладываем: спроси «это готовая версия?».
2. **Проверка на данные клиентов.** Если в названии файла есть номера ДТ, договоров, счетов, БИН или название клиента — переименуй (с согласия человека) или клади в папку, начинающуюся с «_», внутри нужного направления.
3. **Куда.** Направление задачи (из трекера, `get_task`) определяет папку проекта «Цифровизация Тенгри Достык»:
   | Направление | Папка | ID |
   |---|---|---|
   | TradeLab (TL) | TL | `1B9SLMaMG9DLfxznN95O3GRUBxU_QwPKz` |
   | Терминал (TD) | TD | `1EIU2gMwBC_uOf76FaA6ETjnDORloEH9N` |
   | Брокер (XP) | XP | `1jKz6UFq4WKA78Wq26NhUHa5--V9lQxFP` |
   | Система управления (ORG) | корень проекта | `1AoFch44aGAsmVoWEksta18daO35l7joT` |
   Внутри можно создать подпапку по теме, если человек попросит. Существующие файлы на Диске не перезаписывай и не удаляй — новая версия = новый файл с датой или номером версии в названии.
4. **Название.** Понятное: что это и для чего, без кодов и сокращений. Пример: «Перечень документов брокера для оформления ДТ, v2».
5. **Выложить** через Google Drive (создать файл в нужной папке). Документы Word и Markdown — как Google Документ, таблицы — как Google Таблица, если человек не просит иначе.
6. **Ссылка в журнал.** `add_worklog` по задаче: «Выложил на Диск: <название>» и ссылка. Задачи нет — спроси номер.
7. Ответь человеку ссылкой одной строкой.

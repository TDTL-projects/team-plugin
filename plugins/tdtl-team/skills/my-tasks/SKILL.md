# Мои задачи

Отвечаешь как **Архонт** — менеджер проекта (решение D-0016). Если человек обратился «Ариадна, мои задачи» — просто сделай.

1. Вызови инструмент трекера `my_tasks`. Если коннектора «Трекер» нет — скажи, как подключить (страница «Как мы работаем», раздел «Настройка за 20 минут» — https://tl-pm-demo-puce.vercel.app/guide), и остановись.
2. Покажи коротко, по группам — по квадрату приоритета из `my_tasks` (решение D-0038, «срочно / важно»):
   - **Сейчас** (срочно и важно);
   - **жду моей приёмки** — блок «Жду моей приёмки» из `my_tasks`: задачи «На проверке», где принимающий — я. По каждой: «посмотреть результат и принять?» Принял — `update_task` со статусом «Готово»; есть замечания — запись в журнал задачи (навык log-work) и статус «В работе»;
   - **План** (важно, не срочно);
   - **Быстро** (срочно, не важно);
   - остальное — одной строкой: «и ещё N в «Потом»».
   Отдельно — **«Ожидание» дольше 3 дней**: номер, название, чего ждём.
   Для каждой задачи: номер, название и одна строка — почему она в этом квадрате (подсказка из трекера, как её вернул `my_tasks`). Не больше 10 строк всего; остальное — «и ещё N».
   Человек не согласен с квадратом — `set_priority` с причиной (без причины трекер не примет; «авто» возвращает расчёт трекера).
3. Советы Архонта: `list_suggestions`. Каждый — одной строкой, с вопросом «принять?». Ответ человека — `decide_suggestion`. Среди советов бывает «следующая задача» — «да» берёт её в работу.
4. Предложи один следующий шаг: первую задачу из «Сейчас», которую можно начать; в «Сейчас» такой нет — первую из «План». Нет и там — то, где ожидание можно снять. Нет задач «В работе» и нет совета «следующая задача» — найди 1–2 задачи из его проектов, которые можно начинать (навык pm, «Что дальше по проекту»), и спроси, взять ли.

Пиши простым языком, без канцелярита. Не придумывай статусы — только то, что вернул трекер.

## Начало запуска
1. Запомни начало (`date -u +%FT%TZ`) и `run_key` — код повода + время (`queue20261127T1000`).
2. **Повод** — блок `routine-fire-payload` в тексте запуска; по журналам не ищи. Код: Ерлан ответил (и «да») — `answer`, закончился полный прогон — `run_done`, запуск оборвался — `run_broken`, есть задача в очереди — `queue`. Нет блока — очередь (`take_next_for_dev`, TL) или слова человека.
3. **Обрыв**: прошлая сессия ещё пишет (запись «Дедал» моложе 90 минут без «запуск закончен» после) — конец без записей.
4. **Пауза**: `dev_pause` `action: status`. Стоит — новое не берёшь, в `main` не сливаешь.
5. **Пакет**: `task_pack T-…` (нет — `get_task`). Без зоны не берёшь; можешь поставить сам по зерну — `set_dev` с причиной.
6. **Режим** — ниже; прочитай только его файл, целиком.
7. Запись «Дедал: запуск начат — повод …, режим …». Продолжаешь — с шага по журналу.

**Занятость.** Запись хода — перед вызовом роли, после него и не реже раза в час: диспетчер считает тебя работающим, пока твоя запись моложе 90 минут.

# T-0509 «Плагин: техпроект волны описывает только новое; что уже есть в системе — берётся из кода»

Описание задачи из трекера как есть (зерна нет: задачу ведёт сессия Claude Code по плану T-0494, решение D-0106).

Зачем: техпроект волны вырос с 58 КБ (волна 1) до 114 КБ (волна 6). Его читают Архонт, Дедал, Астерион на каждом круге и шаг «спека и тесты» в каждой задаче. Заметная часть — пересказ того, что уже есть в коде прошлых волн.

Результат: техпроект называет, что волна заводит и меняет, и ссылается на существующее по имени (таблица, функция, файл) без пересказа. Обязательные таблицы D-0091 («заводит → пользуются», «кто что видит и делает») остаются, но только про новое и изменённое.

Где: team-plugin — навык dedal («Техпроект волны»), asterion (что проверять в техпроекте).

Кто утверждает: правка asterion — «да» Ерлана; dedal — после ревьюера.

Готово, когда: правило записано; техпроект пробной волны заметно короче волны 6 при том же числе задач, а число замечаний «держит» у Астериона не выросло.

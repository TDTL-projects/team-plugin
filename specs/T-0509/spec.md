# T-0509 — что решено при исполнении

Можно переиграть, PR не слит.

- Размеры техпроектов сверены по репозиторию tradelab-app (`docs/waves/`): волна 1 — 58 КБ, волна 6 — 114 КБ; числа из описания задачи верны.
- Риск правила — «в тексте нет, значит не проверяем». Поэтому Астериону записано проверять по коду: каждое названное имя есть в `main` и работает так, как рассчитывает волна; новое действие над существующим объектом без строки «кому нельзя» — «держит». Проверка техпроекта от этого не короче, а ближе к коду.
- Раздел «перешло из прошлых волн» остаётся, но в нём только отложенное на эту волну — пункт и задача-хозяин или «чего нет» (по ревью: это единственное место, где обещаниям прошлых волн дают хозяина; в волне 6 он занимал 4 КБ).
- Только линия TradeLab (D-0106 п.2).
- Версия плагина и README не тронуты: последним коммитом при слиянии цепочки.
- Не доказано до слияния: «техпроект пробной волны заметно короче волны 6 при том же числе задач, а число замечаний „держит“ у Астериона не выросло».
- По ревью: строка-ссылка на существующее имеет форму — имя из кода, фраза «на что волна рассчитывает», задачи. Фраза-ожидание обязательна и пересказом не считается: по ней Дедал и Астерион сверяют код. Без неё проверять было бы нечего.
- По ревью: у Астериона пропущенное имя существующего объекта, которым задача пользуется, — «держит»; новый экран, список или функция над существующим объектом — это «меняет, кто видит», строка в разделе 3 обязательна.
- По ревью: агенту spec-tests одной фразой сказано, что существующее «как есть» берётся из кода и это не повод отвечать «не хватает данных» (правка проверок — вердикт Астериона; в «Где» задачи агент не назван).
- Оценка ревьюера по техпроекту волны 6: чистого пересказа существующего там около 5 КБ из 114. Основной объём — подробные «решения по данным» (всё новое) и раздел правок проверок, уже урезанный T-0501. То есть одного этого правила для «заметно короче волны 6» не хватит: рычаг — уровень детали «что, а не код», это вне рамки задачи. Вопрос Ерлану.
- По вердикту Астериона к PR #41: шаг «спека и тесты» останавливается, когда код существующего объекта делает не то, что обещает фраза-ожидание техпроекта; существующий объект, которого в названных разделах нет, называет в «Развилках». Дедалу и Астериону добавлен случай, когда новый вид записи, роль или правка общей функции меняют поведение существующего, которое «не трогали».
- К сведению Ерлану: правило добавляет поводы вернуть техпроект, поэтому мерило задачи «число „держит“ у Астериона не выросло» на пробной волне может не сойтись — это цена проверки по коду.

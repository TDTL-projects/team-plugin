# T-0504 «Плагин: Дедал делит волну на независимые цепочки; конвейер при остановке берёт задачу из другой цепочки»

Описание задачи из трекера как есть (зерна нет: задачу ведёт сессия Claude Code по плану T-0494, решение D-0106).

Зачем: в волнах 3–6 связи «зависит от» стояли одной цепочкой («строго по одной»): встала одна задача — стоят все, конвейеру взять нечего. Навык take-task уже говорит «паркуй и бери следующую», но следующей по связям нет.

Результат: в техпроекте Дедал называет, какие задачи волны не делят таблицы, миграции и общие файлы, и ставит связи двумя цепочками там, где это правда так. Задачи с базой по-прежнему идут по одной внутри своей цепочки. Конвейер, припарковав задачу, берёт доступную из другой цепочки. Где цепочку разделить нельзя — так и написано, силой не делим.

Где: team-plugin — навык dedal («Техпроект волны», «Связи и порядок»), wave (шаг 3), take-task («Остановка»). Очередь выдаёт трекер — проверить, что правило «задачи с базой по одной» не мешает.

Кто утверждает: текст dedal и wave — после ревьюера; take-task — вердикт Астериона.

Готово, когда: в техпроекте пробной волны порядок записан цепочками с обоснованием; при остановке одной задачи конвейер взял задачу другой цепочки.

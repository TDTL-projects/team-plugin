# T-0350 — факты из трекера (21.11.2026)

## Инструменты трекера (сверено по схеме коннектора участника «Конвейер»)
- `find_tasks` уже принимает `project`: «P-... или SP-... — только задачи внутри (проект — с подпроектами); -P-... — все, кроме задач этого проекта». T-0349 в «Готово».
- `take_next_for_dev`: «записанный конвейером проекта берёт только задачи своей линии (проекты, где он конвейер), остальные — задачи проектов без конвейера». Разделение очереди держит трекер (T-0349), плагин его не решает — назвать в спеке как условие.
- `update_task`: передача (`owner`/`acceptor` с `reason`) — «такая правка — без других полей»; нужна текущая версия из `get_task`, каждая правка поднимает версию.
- `send_message` есть у коннектора (личное сообщение участнику в Google Chat; `weekend: true` — только по прямой просьбе).

## Замечания Астериона «к сведению» (вердикт версии 18 и прежние)
1. Стыки. Причина остановки «да Ерлана на слияние» сравнивается дословно в take-task («Остановка») и в asterion (раздел 6, шаг 1). Для ТД+XP нужен один точный текст (например, «да Наиля на слияние»), одинаковый в обоих навыках, иначе Мунин не найдёт задачу, которую остановил Паровоз.
2. Безопасность. Ключом Наиля пишет и Claude в его чате. В спеке прямо: что считается «да» Наиля на секреты и боевую базу — его слова в разговоре или его комментарий в задаче трекера от участника «Наиль». Так же сейчас для Ерлана.
3. В проверку добавить вопрос ревьюеру: «засчитает ли Паровоз запись участника «Астерион» по задаче P-08?» — ответ «нет».
4. PR правит навык asterion и правила take-task — сливается только по «да» Ерлана в трекере (стоп-список team-plugin).
5. Обе линии берут задачи ORG через take_next_for_dev — разделение очереди держит только T-0349 (поле «конвейер» у проекта); в спеке назвать как условие, а не решать в плагине.
6. Между двумя правками `update_task` при возврате задачи «вне линий» — новый `get_task`; в тексте навыка — «владелец Наиль» прямо.
7. Рабочие базы DocsSystem — ссылкой на `CLAUDE.md` DocsSystem (T-0355), не вписывать «сервер СЭД» в навык.

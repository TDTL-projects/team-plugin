# T-0502 «Плагин: шаг «спека и тесты» пишет проверки только на своих данных»

Описание задачи из трекера как есть (зерна нет: задачу ведёт сессия Claude Code по плану T-0494, решение D-0106).

Зачем: шесть вопросов Ерлану за 4 дня были про «одну строку теста». Частая причина: тест прежней задачи считает «всё» вместо «своё». Пример: проверка одной задачи считала все письма человека, а не письма по своему заказу, — и следующая задача законно её сломала. Такого правила сейчас нет ни в уроках конвейера, ни в агенте spec-tests.

Результат: агент spec-tests пишет утверждения, привязанные к данным своего теста (свой заказ, своя компания, свой вид записи), а не к общему числу записей в таблице; тест не опирается на значение, которое сам же считает. Правило — в тексте агента и одним пунктом в specs/LESSONS.md репозиториев.

Где: team-plugin — agents/spec-tests.md, agents/reviewer.md (ревьюер сверяет); tradelab-app — specs/LESSONS.md.

Кто утверждает: правка агентов spec-tests и reviewer — правка проверок, вердикт Астериона.

Готово, когда: правило и пример есть в тексте агента; ревьюер называет блокером утверждение «по всей таблице» там, где можно «по своему объекту».

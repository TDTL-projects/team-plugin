# T-0367 «Плагин: навык дирижёра подготовки волны — один запуск сам ведёт Архонта, Дедала и Астериона»

Описание задачи из трекера как есть (зерна нет: задачу ведёт сессия Claude Code по плану T-0494, решение D-0106).

Результат: в плагине tdtl-team есть навык дирижёра. Одна фраза «Дирижёр, готовь волну N» — и он ведёт волну по навыку wave, запуская Архонта, Дедала и Астериона субагентами. Состояние волны держит узел волны в трекере, чтобы продолжить мог любой следующий разговор или запуск.

Правила, на которых держится независимость (из чатов дирижёра 20–22.11):
1. Каждый субагент стартует с чистого листа; тип «копия разговора» для проверяющего не годится.
2. Астериону дают только номера задач и пути к файлам, без пересказа и без мнения автора.
3. Вердикт Астерион пишет в трекер сам, под своим ключом; дирижёр вердикты не пересказывает и не правит.
4. Дирижёр сам ничего не пишет: ни зёрен, ни техпроекта, ни кода.
5. Три круга не сошлись — вопрос Ерлану, а не четвёртый круг.
6. Перед проверкой Астерион смотрит, не взял ли этот PR его запуск по расписанию (в волне 4 один техпроект проверяли двое).

Зачем (как было): при подготовке волны 2 было пять чатов и около 12 ручных передач через Ерлана. Изолированные чаты при этом нашли противоречия, которые один чат пропустил бы, — независимость проверки терять нельзя.

Где: team-plugin — новый навык, правка wave («человек открывает новый чат» → дирижёр), README, версия.

Кто утверждает: текст навыка — после ревьюера; если правится asterion — «да» Ерлана.

Готово, когда: волна подготовлена по фразе, без вставки промпта; правило записано в навык.

Запасной вариант Б: цепочка запланированных задач, каждая роль — своя.

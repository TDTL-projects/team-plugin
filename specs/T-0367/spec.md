# T-0367 — что решено при исполнении

Можно переиграть, PR не слит.

- Навык назван `conductor`; имена остальных навыков плагина тоже латиницей. Обращение — «Дирижёр, …».
- Навык не пересказывает `wave`, `dedal`, `asterion`: в нём только как вести (одно правило — в одном месте).
- Правило 6 («не вдвоём») записано у дирижёра, а не в навыке asterion: он сам смотрит журнал перед запуском проверяющего и одной строкой просит о том же в промпте. Навык asterion не тронут — «да» Ерлана этому PR не нужно.
- Круги дирижёр считает, как Астерион: первая проверка — первый круг. У Астериона и Архонта в их навыках вопрос владельцу — после двух кругов; дирижёр раньше них не решает: вопрос заведён — стоим. Третий круг — только если после второго вопроса нет; четвёртого нет никогда. «Три круга» из описания задачи понято так, чтобы не менять правило проверяющего из чужого навыка.
- Дирижёр пишет в трекер только записи хода (слово «Дирижёр:» в начале), под тем ключом, под которым запущен: до узла — в журнал задачи плана, после — в узел волны. Узел заводит Архонт отдельным запуском сразу после «да» на рамку.
- Текст между ролями дирижёр не носит: каждая роль пишет результат в трекер, следующей даётся номер задачи.
- Два дирижёра на одной волне: запись «Дирижёр: … запущен …» моложе 90 минут — второй не входит (как у конвейера). Запись пишется и перед запуском роли, не только после.
- Правило «не вдвоём» закрывает уже записанный вердикт и расхождение двух вердиктов после проверки. Одновременную проверку (субагент дирижёра и запуск Астериона по расписанию начали разом) оно не видит: метки «проверку начал» у Астериона нет. Завести её — правка навыка asterion, по «да» Ерлана: вопрос в пачку.
- Слово «дирижёр» в take-task уже значит сессию конвейера, которая ведёт очередь; в новом навыке это оговорено. Развести слова — правка take-task, отдельной задачей.
- Обращения сужены до «Дирижёр, …», чтобы не срабатывал навык волны на «готовь волну».
- Только линия TradeLab (D-0106 п.2).
- Строка о новом навыке в README и версия плагина — последним коммитом при слиянии цепочки (слово Ерлана на ночь 23.11.2026: README и версию в этих PR не трогать).
- Не доказано до слияния: «волна подготовлена по фразе, без вставки промпта» — проба на первой волне после слияния.

# T-0505 — что решено при исполнении

Можно переиграть, PR не слит.

- Шаблон зерна в трекере (`get_seed_template`) не меняю: его разделы те же, короткое зерно — это правило, что в них писать. В шаблоне в разделе Дедала стоят строки «Затрагивает» и «Чем проверяется» — у задачи волны их нет; Астериону сказано, что это не пустой раздел. Поправить сам шаблон (две строки с пометкой «текучка») — отдельная маленькая правка трекера, вопрос Ерлану.
- Трекер читает из зерна строку «Меняет базу» (выдача очереди) — она осталась в обоих видах раздела, написана так же.
- «Откуда знаем» и «Вопросы» в коротком зерне оставлены: в описании задачи их нет в перечне, но это не пересказ техпроекта, а посылку Астерион проверяет в каждом зерне.
- «Кому нельзя» остаётся пунктом «Готово, когда» со ссылкой на строку таблицы «роль × действие»: это проверяет приёмка.
- Пересказ техпроекта теми же словами — «к сведению», иначе — «держит». Жёстче («любой пересказ держит») не стал: вернуло бы зёрна за форму.
- Только линия TradeLab (D-0106 п.2); текучка и ТД+XP — полный раздел, как раньше.
- Версия плагина и README не тронуты: последним коммитом при слиянии цепочки.
- Не доказано до слияния: «на пробной волне зёрна прошли проверку не больше чем за два круга, а конвейеру хватило зерна и техпроекта».
- По ревью: разделы и строки техпроекта задачи называет один — Дедал, строкой «Техпроект»; Архонт в «Ссылках» называет только файл. Иначе списки двух авторов разошлись бы — та самая ошибка, которую задача убирает.
- По ревью: Астерион находит строки задачи в техпроекте сам, по номеру задачи; неполная или мёртвая ссылка — «держит». Без этого появлялась лазейка «в зерне нет — не проверяем».
- По ревью: оговорка «линия TradeLab» стоит у каждого пункта навыка волны и в самопроверке; для ТД+XP прежний текст возвращён.
- Не сделано здесь, отдельными правками (вопросы Ерлану): 1) в списке ревьюера пункт «рамки» у задачи волны «идём по зерну» стоит сказать прямо — «строки задачи в техпроекте» (правка агента reviewer, вердикт Астериона); 2) что делает конвейер, когда шаг «спека и тесты» ответил «не хватает в техпроекте», — сейчас он дополняет data.md, а надо просить Дедала дописать техпроект (правка take-task).

Поэтому Астерион пишет вердикты по задетым зёрнам заново до слияния PR правки техпроекта. И строка «Техпроект» называет не только разделы 2–6, а любой раздел, где есть правило этой задачи.

# T-0505 «Плагин: короткое зерно — зачем, «готово, когда», чего не делаем и ссылки на разделы техпроекта, без пересказа»

Описание задачи из трекера как есть (зерна нет: задачу ведёт сессия Claude Code по плану T-0494, решение D-0106).

Зачем: об одном и том же сейчас четыре слоя текста — решение, техпроект, зерно, спека. Главный вид ошибок при подготовке волн — «зерно спорит с техпроектом» и «после ответа остался старый текст». Зерно пишут двое по очереди (Архонт и раздел Дедала), каждая правка поднимает версию и сжигает вердикт: в волне 5 зёрна дошли до версии 9.

Результат: зерно задачи волны — «зачем», «кто пользуется и пример», «готово, когда» (до шести пунктов), «что не делаем» и ссылки на разделы техпроекта. Таблицы, права, файлы и «что не краснеет» в зерно не переписываются — их источник техпроект. Раздел Дедала — репозиторий, меняет ли базу, порядок, разделы техпроекта, приёмка. Текучка (одиночная задача без техпроекта) пишется как раньше.

Где: team-plugin — навыки pm, wave, dedal, asterion (что проверять в коротком зерне), агент spec-tests (читает техпроект по ссылкам); шаблон зерна в трекере (get_seed_template) — при необходимости отдельной правкой трекера.

Кто утверждает: правка asterion — «да» Ерлана; spec-tests — вердикт Астериона; остальное — после ревьюера.

Готово, когда: шаблон и правила короткого зерна записаны; на пробной волне зёрна прошли проверку не больше чем за два круга, а конвейеру хватило зерна и техпроекта без вопросов «чего нет в зерне».

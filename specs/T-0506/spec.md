# T-0506 — что решено при исполнении

Можно переиграть, PR не слит.

- «Не взял ли этот PR другой запуск» сделано новой меткой «Астерион: проверку начал — …» в журнале задачи плана: другой запуск или субагент дирижёра видит её и не берёт ту же проверку 90 минут (порог — как у конвейера и дирижёра). Это закрывает и предел, записанный в T-0367 у дирижёра: его навык поправлен здесь же.
- «Коммит виден на GitHub»: Дедал называет коммит в записи «Дедал: самопроверка — … (коммит …)»; Астерион сверяет его с последним коммитом PR и не тратит круг на старый текст.
- Запись самопроверки Дедала — она же «готово к проверке»; отдельной метки не завожу.
- Уроки из сводки по техпроекту ждут общего PR в конце подготовки. Они нужны будущим волнам, а не этой; дыра в стороже по-прежнему сразу идёт задачей на починку.
- Только линия TradeLab (D-0106 п.2): в ТД+XP техпроект и уроки — как раньше. Метка «проверку начал» записана без оговорки линии: она ничего не ослабляет и нужна там, где проверяют двое.
- Версия плагина и README не тронуты: последним коммитом при слиянии цепочки.
- Не доказано до слияния: «на пробной волне техпроект слит одним PR и уроки одним PR; двойной проверки не было».

# T-0506 «Плагин: техпроект волны — одна ветка и одно слияние; уроки — одним PR в конце волны; один проверяющий на PR»

Описание задачи из трекера как есть (зерна нет: задачу ведёт сессия Claude Code по плану T-0494, решение D-0106).

Зачем: в волне 6 техпроект прошёл три PR плюс PR уроков; первый слили раньше вердикта второго круга. Уроки вносятся дважды за волну (после проверки техпроекта и после проверки зёрен). В волне 4 один техпроект проверяли два Астериона сразу — по расписанию и субагент дирижёра. В волне 5 правки Дедала не дошли до GitHub, и круг проверки прошёл впустую.

Результат:
1. Техпроект волны живёт в одной ветке и одном PR: круги проверки идут в ней, сливается один раз, после записи «Астерион: техпроект проверен». Правка после зёрен — второй PR, только если она нужна.
2. Уроки волны — одним PR в конце подготовки, а не после каждого круга.
3. Перед проверкой Астерион смотрит, не взял ли этот PR другой его запуск; автор перед «готово к проверке» сверяет, что коммит виден на GitHub.

Где: team-plugin — навыки wave (шаги 3, 6), dedal, asterion (раздел 1 и «По расписанию»).

Кто утверждает: правка asterion — «да» Ерлана; остальное — после ревьюера.

Готово, когда: на пробной волне техпроект слит одним PR и уроки одним PR; двойной проверки одного PR не было.

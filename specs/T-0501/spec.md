# T-0501 — что решено при исполнении

Можно переиграть, PR не слит.

- Четыре пункта проверки («поведение по зерну правда делает строку неверной; правка узкая; ловит ту же ошибку; смысл зерна не меняется») перенесены из раздела 1 навыка asterion в раздел 2 без изменения: правило «стала ли проверка слабее» то же.
- Запись конвейера «Конвейер: правка проверок вне зерна — …» осталась, но теперь это пометка в журнале и строка в PR, а не остановка.
- Причина остановки «вердикт Астериона по зерну» осталась для своего прямого случая (задача выдана без проверенного зерна). Старые остановки на правке вне зерна дорабатываются по прежнему порядку — он оставлен коротким абзацем в обоих навыках.
- Астерион при проверке зерна больше не возвращает зерно за непредсказанный тест прежней задачи: это «к сведению». «Держит» — когда тест покраснеет там, где поведение по зерну меняться не должно.
- Дедал в техпроекте называет намеренные изменения поведения; конкретный тест — подсказка, не обязанность.
- В T-0511 (красный полный прогон) Астерион сам писал правку теста прежней задачи записью по зерну — здесь это упрощено до общего порядка: доделка, конвейер правит, вердикт в PR.
- Версия плагина и README не тронуты: последним коммитом при слиянии цепочки.
- Не доказано до слияния: «правка вне зерна прошла за одну остановку и один вердикт» — увидим на первой такой задаче после слияния.

# T-0501 «Плагин: правка старого теста — один вердикт Астериона в PR, без отдельного вердикта по зерну»

Описание задачи из трекера как есть (зерна нет: задачу ведёт сессия Claude Code по плану T-0494, решение D-0106).

Зачем: какие тесты прежних задач покраснеют, сейчас предсказывают на бумаге: Дедал в техпроекте, Астерион при проверке зерна. Урок «что покраснеет — по памяти» повторился в волнах 4, 5 и 6, а волна 6 после трёх кругов проверки всё равно встала ночью на непредсказанном тесте. Когда правки в зерне нет, вердиктов два — по зерну и по PR: на одну такую задачу ушло четыре сессии Конвейера и три Астериона.

Результат: покраснел тест прежней задачи, а код сделан по зерну — конвейер правит только эту строку, объясняет в спеке и в PR, и Астерион выносит один вердикт в PR («проверка не ослаблена» или «ослаблена»). Остановки «вердикт Астериона по зерну» ради такой правки нет. Техпроект называет только намеренные изменения поведения, а не список тестов.

Где: team-plugin — take-task (п.3, п.4, п.9, «Остановка»), asterion (раздел 1 «Правка проверок вне зерна», раздел 2), dedal (таблица «что покраснеет»), агент spec-tests.

Кто утверждает: правка asterion — «да» Ерлана; остальное — вердикт Астериона.

Готово, когда: правка проверки вне зерна проходит за одну остановку конвейера и один вердикт; правило «стала ли проверка слабее» не изменилось.

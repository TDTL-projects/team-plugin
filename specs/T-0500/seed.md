# T-0500 «Плагин: вопросы не про секреты и боевую базу решает Астерион; Ерлану — одна утренняя сводка с возможностью отката»

Описание задачи из трекера как есть (зерна нет: задачу ведёт сессия Claude Code по плану T-0494, решение D-0106 п.4).

Зачем: за 19–23.11 конвейер четыре ночи из четырёх вставал на вопросе к Ерлану — около 41 часа простоя из 96. Задачи идут цепочкой, поэтому одна остановка держит всё.

Результат: остановку конвейера с вопросом, который не про секреты и не про боевую базу, решает Астерион своим вердиктом. Решение он записывает в журнал задачи: что решил, почему, как откатить. Ерлану — одно уведомление утром со всеми ночными решениями. За Ерланом остаются секреты, боевая база и то, что Астерион сам назвал «не ясно».

Где: team-plugin — навыки asterion и take-task (раздел «Остановка»). Правила T-0447 «противоречивый тест» и T-0486 «правка проверки вне зерна» входят сюда как частные случаи.

Кто утверждает: правка навыка asterion и правил «что сливается без Ерлана» — «да» Ерлана на слияние.

Готово, когда: в навыках названо, какие вопросы решает Астерион и какие остаются Ерлану; формат утренней сводки описан; на пробной ночной остановке конвейер продолжил без Ерлана.

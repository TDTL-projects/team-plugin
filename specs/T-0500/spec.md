# T-0500 — что решено при исполнении

Можно переиграть, PR не слит.

- Только линия TradeLab: D-0106 п.2 — «линию ТД+XP пока не трогаем».
- Владельцу остаются, кроме секретов и баз: деньги (платный сервис, тариф, лимиты), удаление данных и то, что нельзя вернуть отменой PR, новый внешний сервис — это уже было «только по да» в разделе 5 навыка asterion и в брифе плана.
- Астерион решает, только когда ответ следует из уже решённого (зерно, техпроект, решения, правила репозитория) и откатывается отменой PR; иначе — «не ясно», владельцу.
- Вопрос по-прежнему заводится записью Q-… (D-0027): меняется только адресат задачи «Ответить на Q-…».
- Утренняя сводка — первый запуск рабочего дня после 08:00 по Алматы.
- Версия плагина и README не тронуты: поднимаются последним коммитом при слиянии цепочки.
- Не доказано до слияния: «на пробной ночной остановке конвейер продолжил без Ерлана».
- Задачу «Ответить на Q-…» Астерион не закрывает: по правилам базы «Готово» ставит принимающий — конвейер, который задал вопрос. Астерион переводит её в «На проверке».
- Решение засчитывается по записи участника «Астерион» в журнале задачи, а не по тексту ответа на вопрос: кто закрыл вопрос, коннектор не показывает.
- Откат: Ерлан пишет комментарий в задаче; Астерион читает такие комментарии в каждом запуске и помнит обработанное по записи «Астерион: откат решения по Q-… — …».
- Сводка короткая (число и номера задач, по фразе на решение), подробности и «как откатить» — в журналах задач.
- Не сделано здесь, отдельная правка трекера по «да» Ерлана: эстафета и диспетчер (tl-pm-demo) новых записей не знают — остановка с вопросом не будит Астериона, его решение не будит конвейер, оба ждут расписания.
- Слияние PR «T-0500 …» само поставит задаче «Готово»; закрытой её считать после пробной ночи.

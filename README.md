# Плагин команды TDTL

Навыки Claude для работы команды автоматизации с трекером.

| Навык | Что делает |
|---|---|
| `how-we-work` | где что лежит, направления, статусы, правила |
| `my-tasks` | мои задачи, что горит, советы бота |
| `log-work` | запись в журнал задачи |
| `new-task` | новая задача, решение или вопрос |
| `pm` | менеджер проекта: разложить работу, следующий шаг, зерно задачи на разработку |
| `take-task` | для разработчиков в Claude Code: задача → спека → код → PR |

Агенты (Claude Code и Cowork): `cto` — спека из зерна, `reviewer` — проверка изменений.

Установка в Claude Code:

```
/plugin install tdtl-team --marketplace TDTL-projects/team-plugin
```

В приложении Claude: Customize → Plugins → Add → Add marketplace → Add from a repository → `TDTL-projects/team-plugin`.

Навыкам нужен коннектор «Трекер». Как подключить Claude к трекеру и поставить плагин — документ «Как подключить Claude к трекеру» в папке проекта на Google Диске.

Правки навыков — через PR в этот репозиторий. После слияния плагин обновится у всех, у кого включена синхронизация маркетплейса.

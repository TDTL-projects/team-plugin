# Ариадна — плагин команды TDTL

Навыки Claude для работы команды автоматизации с трекером. Помощников двое (решение D-0016):

- **Ариадна** — порядок и журналы: «Ариадна, запиши», «Ариадна, заведи задачу», «Ариадна, выложи на Диск», «Ариадна, наведи порядок в TD».
- **Архонт** — менеджер проекта: «Архонт, мои задачи», «Архонт, что дальше по P-01», «Архонт, разложи T-…».

Обычные фразы без имени тоже работают; перепутанное имя не мешает — навык выбирается по делу.

| Навык | Кто | Что делает |
|---|---|---|
| `how-we-work` | оба | кто за что отвечает, где что лежит, направления, статусы, рабочая папка, правила |
| `log-work` | Ариадна | запись в журнал задачи |
| `new-task` | Ариадна | новая задача, решение или вопрос |
| `publish-to-drive` | Ариадна | выложить готовый файл из рабочей папки на общий Диск, сразу привязать к задаче и записать ссылку в журнал |
| `tidy-drive` | Ариадна | навести порядок в папке направления на Диске: номер задачи в названии, привязка к задаче, старое — в «Референс», дубли; только по «да» |
| `my-tasks` | Архонт | мои задачи, что горит, советы Архонта, что брать дальше |
| `pm` | Архонт | что дальше по проекту (что можно начинать и что держит), разложить задачу или работу, зерно на разработку, «готово к разработке?» |
| `take-task` | — | для разработчиков в Claude Code: задача → спека → код → PR |

Боты трекера по расписанию подписаны так же: опись Диска и сводки журналов — «Ариадна», советы в трекере и утреннее сообщение в общий чат — «Архонт».

Агенты (Claude Code и Cowork): `cto` — спека из зерна, `reviewer` — проверка изменений.

Установка в Claude Code:

```
/plugin marketplace add TDTL-projects/team-plugin
/plugin install tdtl-team@tdtl
```

`tdtl` — имя маркетплейса из `.claude-plugin/marketplace.json`.

В приложении Claude: «Персонализация» → «Плагины» → «+ Добавить» → «Добавить маркетплейс» → `TDTL-projects/team-plugin`.

Навыкам нужен коннектор «Трекер», навыку `publish-to-drive` — ещё коннектор Google Drive. Как всё устроено и как подключить — страница [«Как мы работаем»](https://tl-pm-demo-puce.vercel.app/guide) на сайте трекера (пункт в меню сайта), раздел «Настройка за 20 минут».

Правки навыков — через PR в этот репозиторий; при каждой правке поднимать `version` в `plugins/tdtl-team/.claude-plugin/plugin.json`. После слияния плагин обновится у всех, у кого включена синхронизация маркетплейса.
